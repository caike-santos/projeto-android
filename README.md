# História do Mascote do Android - Desafio 10 (Curso em Vídeo)

Este é um projeto desenvolvido como parte do Desafio 10 do [Curso em Vídeo](https://www.cursoemvideo.com/), criado por Caíke Tadeus. O objetivo deste projeto é apresentar um site responsivo e bem estruturado contando a curiosa história por trás da criação do mascote do Android (o Bugdroid).

## 💻 Tecnologias Usadas

O projeto foi construído utilizando as principais tecnologias base do desenvolvimento web front-end:

*   **HTML5:** Estruturação semântica do conteúdo.
*   **CSS3:** Estilização, layout responsivo e design visual do site.

## 🚀 Funcionalidades e Estrutura

*   **Design Responsivo:** O site se adapta a diferentes tamanhos de tela (desktop, tablets e smartphones), utilizando media queries e a tag `<picture>` para carregamento otimizado de imagens.
*   **Fontes Personalizadas:** Integração com o Google Fonts (Bebas Neue) para uma tipografia mais atrativa e alinhada ao tema.
*   **Mídia Incorporada:** Utilização de vídeos do YouTube incorporados via `<iframe>` para enriquecer o conteúdo.
*   **Organização Semântica:** Uso adequado de tags HTML5 como `<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<nav>` e `<footer>`.
*   **Estilo Visual:** Uso de propriedades CSS modernas para caixas, sombras, bordas arredondadas e organização do layout.

## 📁 Estrutura de Arquivos

*   `index.html`: O documento HTML principal contendo a estrutura e o conteúdo da página.
*   `estilos/style.css`: O arquivo de folha de estilos contendo todas as regras CSS.
*   `imagens/`: Diretório contendo todas as imagens utilizadas no projeto (fotos, ícones, versões otimizadas).
*   `fontes/`: Diretório destinado a fontes locais (caso aplicável).

## 💡 Sobre o Projeto

O artigo apresenta desde a primeira e bizarra versão do mascote criada por Dan Morrill (os Dandroids) até a versão final e conhecida mundialmente criada pela ilustradora russa Irina Blok (o Bugdroid). Além disso, há uma seção de curiosidades listando as versões do sistema operacional Android, que tradicionalmente recebiam nomes de doces.
